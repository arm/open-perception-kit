# Legacy ampperformance page

This page is kept only as a compatibility route for older links.

Use the current canonical documentation instead:

- [ampperformance](ampperformance.md)

That page documents the current behavior:

- `ampperformance` publishes formatted metrics into `Perception::perfdata`
- `amposd` is the element that renders those metrics onto the video frame
- `PerformanceTracer` provides the underlying timing and aggregation support
