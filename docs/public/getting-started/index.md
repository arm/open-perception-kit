# Get Started

Use these pages to choose the right first-run path for Perception XPK.

## Quick starts

- [Raspberry Pi 5](raspberry-pi-quick-start.md): run Perception XPK on a Raspberry Pi 5 target.
- [Windows](windows-quick-start.md): use WSL, Docker Desktop, and VS Code.
- [Linux](linux-quick-start.md): use Docker Engine and a local VS Code Dev Container.
- [macOS](macos-quick-start.md): use Docker Desktop and a local VS Code Dev Container.

## Setup references

- [Raspberry Pi SSH setup](raspberry-pi-ssh.md): enable and test SSH before connecting from VS Code.
- [GitHub SSH key setup](github-ssh-key.md): clone with SSH when HTTPS is not suitable.
