# How-To Guides

Use these guides after the first sample pipeline works.

- [Use your own media](media-input.md): switch from sample media to your own images, videos, or streams.
- [Use a camera](camera-input.md): run inference with a USB camera or Raspberry Pi camera.
- [Run Hailo inference](run-hailo-inference.md): use supported Hailo accelerator hardware.
- [Bring your model](bring-your-model.md): add a model through descriptors, OpChains, and pipeline presets.
- [Custom postprocessing](custom-postprocessing.md): add a parser when existing postprocessors are not enough.
- [Feed inference into an application](use-output-in-app.md): planned application-output workflow.
- [Performance measurement](performance-measurement.md): measure the pipeline with Performix.
